## 🚀 Featured Project

### Robot Sensor Localization

A project I built from scratch to understand how robots estimate where they are.

I explored:

- GPS and IMU sensor simulation
- Sensor noise and bias
- Dead reckoning and accumulated drift
- Kalman filtering
- GPS + IMU sensor fusion
- 2D robot localization
- Machine learning for position estimation
- Linear Regression vs Random Forest
- RMSE-based localization evaluation

One of my biggest takeaways was that **more complicated doesn't always mean better** — good localization depends on understanding sensor uncertainty, drift, motion models, and how different sources of information should be combined.

🔗 [View the project](https://github.com/Anderoids/robot-sensor-localization)
